These workspace fixtures were generated by the authenticated GNU R oracle in
`oracle/r-oracle.json`: source commit
`bac583951b728e97b9786804d3b4081f0fe18df5`, SVN revision 90451.

Run `generate.R OUTPUT_DIRECTORY` with that oracle's `Rscript --vanilla` to
reproduce the six files. A separate rerun reproduced every byte. The generator
also loads each file in GNU R and checks values, attributes, loaded names,
shared environment identity, and the environment's self-reference.

The files cover uncompressed XDR versions 2 and 3, gzip, bzip2, XZ and ASCII.
Each contains a data frame with factor and Date columns, a shared cyclic
environment, NULL, and a named integer vector containing NA. Production tests
load these original bytes; they do not use the port's serializer to construct
their expected input.
