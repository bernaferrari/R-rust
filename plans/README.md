## Findings considered and rejected

- Pixel-for-pixel imitation of desktop RStudio: rejected. A phone/tablet
  workbench should preserve workflows and semantics, not copy a desktop layout.
- Claiming whole-GNU-R or full-RStudio parity from the current 577 fixtures:
  rejected. Those fixtures are useful but heavily weighted toward scalar/base
  functions and contain only 11 evaluator, 5 package/S3, and 2 graphics cases.
- A one-shot rewrite of the 30,000-line `essentials.rs`: rejected. Extract
  subsystems only after characterization tests; a bulk rewrite would increase
  pointer-lifetime and semantic risk.
- Enabling arbitrary native CRAN extensions immediately: rejected. The mobile
  policy deliberately disables them, and the dormant `.Call` dispatcher is not
  safe for broad arities. Treat this as a multi-release compatibility program.
