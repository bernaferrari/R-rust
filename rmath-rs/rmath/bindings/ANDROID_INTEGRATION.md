# Android Integration Guide

This guide shows how to embed the rmath-rs R interpreter in an Android app using UniFFI-generated Kotlin bindings.

## Prerequisites

- Android NDK (r25 or later)
- `cargo-ndk`: `cargo install cargo-ndk`
- Rust Android targets:
  ```bash
  rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
  ```

## Building the Native Library

From the workspace root (`rport/`):

```bash
cargo ndk -t aarch64-linux-android -t armv7-linux-androideabi -t x86_64-linux-android -o android/app/src/main/jniLibs build --release -p rmath --features rust-backend
```

This produces `.so` files in `android/app/src/main/jniLibs/`:
```
arm64-v8a/librmath.so
armeabi-v7a/librmath.so
x86_64/librmath.so
```

## Kotlin Bindings

The Kotlin bindings are auto-generated by UniFFI. The latest generated file is at:

```
bindings/uniffi/rmath/rmath.kt
```

Copy this file into your Android project (e.g., `android/app/src/main/java/uniffi/rmath/rmath.kt`).

> **Note:** The Kotlin file uses JNA. Add JNA to your app's `build.gradle`:
> ```gradle
> implementation "net.java.dev.jna:jna:5.14.0@aar"
> ```

## Sample Usage

```kotlin
package com.example.myapp

import android.graphics.Bitmap
import uniffi.rmath.*

class RInterpreter {
    private val session = RSession()

    fun evalCode(code: String): String {
        val result = session.eval(code)
        return result.output
    }

    fun listVariables(): List<VariableInfo> {
        return session.listVariables()
    }

    fun getVariable(name: String): String {
        return session.getVariable(name)
    }

    fun removeVariable(name: String): Boolean {
        return session.removeVariable(name)
    }

    fun captureOutput(code: String): String {
        return session.captureOutput(code)
    }

    fun mathSqrt(x: Double): Double {
        return session.mathUnary(RMathFunc.Sqrt, x)
    }

    fun dnorm(x: Double, mean: Double, sd: Double): Double {
        return session.dnorm(x, mean, sd, log = false)
    }

    // Plotting
    fun plotScatter(x: List<Double>, y: List<Double>, w: Int = 800, h: Int = 600): Bitmap {
        val img = session.plotScatter(x, y, w.toUInt(), h.toUInt())
        return Bitmap.createBitmap(img.rgbaBytes.toIntArray(), img.width.toInt(), img.height.toInt(), Bitmap.Config.ARGB_8888)
    }

    fun plotHistogram(data: List<Double>, breaks: Int = 10, w: Int = 800, h: Int = 600): Bitmap {
        val img = session.plotHistogram(data, breaks.toUInt(), w.toUInt(), h.toUInt())
        return Bitmap.createBitmap(img.rgbaBytes.toIntArray(), img.width.toInt(), img.height.toInt(), Bitmap.Config.ARGB_8888)
    }

    // Data frames
    fun createDataFrame(name: String, columns: List<List<Double>>, colNames: List<String>): Boolean {
        return session.createDataFrame(name, columns, colNames)
    }

    fun createMatrix(name: String, data: List<Double>, nrow: Int, ncol: Int): Boolean {
        return session.createMatrix(name, data, nrow, ncol)
    }

    fun close() {
        session.close()
    }
}
```

## Activity Example

```kotlin
class MainActivity : AppCompatActivity() {
    private lateinit var r: RInterpreter

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        r = RInterpreter()

        val output = r.evalCode("x <- 42; x + 8")
        println(output) // [1] 50

        val vars = r.listVariables()
        for (v in vars) {
            println("${v.name}: ${v.type_name} = ${v.preview}")
        }
    }

    override fun onDestroy() {
        super.onDestroy()
        r.close()
    }
}
```

### `PlotImage`

```kotlin
data class PlotImage(
    val width: UInt,
    val height: UInt,
    val rgbaBytes: List<UByte>
)
```

Convert to Android `Bitmap`:
```kotlin
fun PlotImage.toBitmap(): Bitmap {
    val pixels = IntArray(rgbaBytes.size / 4)
    for (i in pixels.indices) {
        val r = rgbaBytes[i * 4].toInt()
        val g = rgbaBytes[i * 4 + 1].toInt()
        val b = rgbaBytes[i * 4 + 2].toInt()
        val a = rgbaBytes[i * 4 + 3].toInt()
        pixels[i] = (a shl 24) or (r shl 16) or (g shl 8) or b
    }
    return Bitmap.createBitmap(pixels, width.toInt(), height.toInt(), Bitmap.Config.ARGB_8888)
}
```

### `RMathFunc` (enum)

### `RBesselFunc` (enum)

## Thread Safety

Each `RSession` owns its own memory arena and environment. Create one session per thread. Do not share a single `RSession` instance across multiple threads concurrently.

## ProGuard / R8

If using minification, add to `proguard-rules.pro`:

```proguard
-keep class uniffi.rmath.** { *; }
-keep class com.sun.jna.** { *; }
```

## Troubleshooting

**`UnsatisfiedLinkError: dlopen failed: library "librmath.so" not found`**
- Ensure the `.so` files are in the correct `jniLibs/<abi>/` directories for all target ABIs.

**`ClassNotFoundException: com.sun.jna.Native`**
- Add the JNA AAR dependency to your app's `build.gradle`.

**Type errors with UniFFI generated code**
- Ensure the Kotlin bindings were generated from the same library version you're shipping. Regenerate after every Rust API change.
